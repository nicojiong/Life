# 《浮生》设计文档 v0.2（街景版）

> 一句话：**你在北宋一个村子里出生，点地走动、点人说话、点屋做事，从六岁活到死。**

本文档描述的是当前实际实现的版本。早期那版"文字卡片"设计已废弃并删除。

---

## 1. 核心循环

```
走动（点地面）
  → 选一件事（进某间屋 / 找某个人）
  → 花掉 1–12 个月，钱与属性变化
  → 时间推进，遇事（说亲、讨账、开张、及冠、死亡）
  → 墓志
```

一局约 50–80 次点击。

---

## 2. 时间

| 维度 | 规则 | 影响 |
|---|---|---|
| 月份 | 由**行动**推进，每次 1–12 个月 | 年龄、属性、店铺行情、季节 |
| 时辰 | 真实时间流逝，一天约 13 分钟 | 只影响光线（昼夜），不影响数值 |
| 季节 | 按月份（2–4 春 / 5–7 夏 / 8–10 秋 / 11–1 冬） | 画面色调，冬天落雪 |

> 昼夜是氛围，不是资源。这是刻意的：如果昼夜影响数值，玩家就得站着等天黑，那不是这个游戏想要的节奏。

---

## 3. 世界

- **地图**：3200×1900，一屏 1280×800，右上角小地图。
- **镜头**：**手动**。右键拖动平移、方向键/WASD 平移、点小地图跳转、按 F 回到人物；人不在画面里时屏幕边缘有红点提示。镜头不跟随，是为了让玩家能"站远一点看这个村子"。
- **寻路**：40px 网格 A\*，房屋、树木、河都算障碍；点到障碍物后面会绕行。
- **地点（22 处 + 空地）**：家、私塾、田、市集、书院、寺庙、衙门、茶肆、药铺、祠堂、铁匠铺、酒肆、当铺、瓦舍、桑园、染坊、客栈、校场、码头、坟地、菜园、打谷场；16 岁后村口空地可盘铺子。
- 每处 2–3 个行动，行动 = 月数 + 花费 + 属性增减 + 一句结果。

**属性**：钱、学识、技艺、声望、身体。全部只显示模糊词（无/薄/略/寻常/颇/甚/极），只有店铺账目显示精确数字——因为经营本来就该算账。

---

## 4. 人

- **10 个有名字的人**：李婶、王秀才、张屠户、老僧、货郎、里正、稳婆、游医、船夫、老塾师。各自守在一处，头上有名字，点他 → 走过去 → 说话。
- **8 个无名路人**：只走动，不可交互，用来让街上有活气。
- **对话是单层选项**：每个选项对应明确的取舍（花时间换学识、花钱换身体、借钱留账），选完即走。暂不做分支树与人物记忆。
- **故事节点**：
  - **14 岁**：媒人上门（应下 = 三贯聘礼 + 婚姻，写进墓志；再等 = 无）。
  - **22 岁**：如果借过李婶的米，债主上门（还三贯 / 赖账 / 求宽限）。三种结局在墓志里各有写法。

## 5. 营生

16 岁后村口空地可盘铺子，三选一：包子铺 8 贯 / 绸庄 18 贯 / 首饰铺 30 贯。

| 机制 | 规则 |
|---|---|
| 进货 | 按当前行情价买入一批（包子 200 个、绸 40 匹、首饰 12 件） |
| 定价 | 贱卖 / 平价 / 贵卖：单价倍率 0.8 / 1.0 / 1.4，需求倍率 1.35 / 1.0 / 0.62 |
| 行情 | 每月在 0.70–1.40 漂移，影响进货价与售价 |
| 同行 | 有 10% 概率改价；你比同行贵则客流 ×0.72，便宜则 ×1.18 |
| 伙计 | 月钱 150 文，走货能力 ×1.6；没货也照付 |
| 重装 | 八贯，等级 +1，走货能力 +18% |

一次"开门做半年生意"会返回：卖出多少、进账多少、净赚多少。

## 5.0 童年（0–6 岁）

游戏从**出生**开始：先播「生」的过场（年号、籍贯、父母姓名），然后 0 岁。

- **父母是有身份的人**：出生过场就会报出「父亲冯福，是个做手艺的。母亲高氏，性子温和。」
  - 父亲的**行当**由出身决定（农 / 匠 / 商 / 兵 / 吏），决定家门口那句台词（刨木头 / 算账 / 磨刀 / 抄文书 / 修农具）。
  - 母亲的**性情**随机（和 / 严 / 病），决定台词与童年事件（严母会问「活干完了吗」，病母靠在床头咳嗽）。
- **孩子没有选择权**：0–6 岁时「家」只有**一个**选项——「跟着父母过日子（一年）」。点一次过一年，这一年发生什么由父母决定。
- **0–2 岁不会走路**：小人不能寻路，点地面只会得到一句「你还不会走，母亲抱着你」；画面上是一小团襁褓，位置跟着母亲走。2 岁那年播「学步」过场（母亲退开三步张开手），之后才真正能走。
- **由父母引导**：每年从 14 条童年事件里抽一条，按父亲行当、母亲性情、家里穷不穷来筛选。例：
  - 父亲是匠人 → 「把一块边角料塞给你，教你削一把木剑」（技艺 +2）
  - 父亲是吏 → 「握着你的手描了一个『人』字。那是你认得的第一字」（学识 +3）
  - 家里揭不开锅 → 「母亲把陪嫁的银镯子当了，回来时手是空的」（+800 文，记下「当镯」）
  - 母亲病着 → 「她自己咳了半年，你自己学会了自己穿衣裳」
  - 严母 → 「你打碎了碗，罚跪半个时辰，跪完又给你留了饭」
- 这段时期**去不了别处**：每个地点有最小年龄（私塾 6、市集 8、书院 12、酒肆 12、衙门 14、校场 16……），太小的时候面板只显示「（等你长到 X 岁再来）」。
- 四个童年节点：**1 岁抓周**（过场，七样东西）、**2 岁学步**（过场，从此能自己走）、**3 岁会说话**（提示）、**6 岁开蒙**（过场，从此可以自己出门）。

这样前 6 年只有 6 次点击，而且**每次都不是你的决定**——这正是童年该有的样子。

## 5.0.1 换视角：替父母过他们的余生

孩子 0–6 岁这段，你可以**切换去操控父亲或母亲**，把他们的后半辈子也过完。

- **怎么切**：**屏幕左下角常驻三个按钮「父亲 / 母亲 / 自己」**，当前那个显示为「·当前」且不可点。<br>也可以点门口的父亲或母亲 →「接过父亲的日子（切换视角）」，切回去点孩子 →「换回来，做你自己」。
- **各人有各人的账**：年龄、身体、学识、技艺、声望、寿数、各条职业线的等级、身上的事（story）都分别保存。**钱是全家共用的**——父亲挣的，孩子也能花。
- **世界时间共用**：你替父亲过一年，孩子也长一岁。切回去时孩子是 1 岁，不是 0 岁。
- **父母有自己的起点**：父亲 25–34 岁，按行当给不同家底——匠人父亲技艺 52 且已是「匠人」，商贾父亲是「行商」，军户父亲是「乡兵」，吏员父亲学识 48，农家父亲是佃农。母亲 22–30 岁，身体偏弱。
- **他们也会死**：替父母过日子时寿数到了或身体垮了，会播过场（「你还不懂死是什么，只觉得屋里忽然很静」），然后自动切回孩子，这个家从此由你自己撑。

这也解释了游戏开头那句「每个人都是 NPC」——你现在既能当那个被养的孩子，也能当养他的人。

## 5.0.2 人物模型

人和人不再用同一根竖线表示。所有人物（含玩家）共用一套程序化绘制 `_draw_figure`：

| 部件 | 做法 |
|---|---|
| 体格 | 四套骨架：**高壮 / 中等 / 矮胖 / 瘦高**（身高 28.5–34.5、肩宽 13–17.5、腰宽 8–12.5、头半径 6.2–6.9）。有名字的人按 id 哈希固定一套，路人随机 |
| 袍身 | 梯形，肩窄摆宽；女性裙摆压到脚踝 |
| 内部线 | 肩线（暗）、衣襟斜线（亮）、腰带（更暗）——三层明暗把一整块色分出结构 |
| 手臂 | 比袍身暗一档，露在两侧，走动时前后摆；末端有手 |
| 头 | 圆头 + 脖子；男性幞头、女性双髻垂发、货郎头巾、僧人光头（另加斗笠） |
| 影子 | 随肩宽缩放 |

玩家的体格由出身决定：军户 → 高壮，士人 → 瘦高，匠户 → 矮胖，其余中等；孩子缩到 64%。

## 5.0.3 母亲的妇业

母亲不是只会抱孩子的背景板。切到她之后，「家」的面板变成她自己的一条路：

| 阶 | 条件 | 能做的 |
|---|---|---|
| 白身 | — | 接第一份浆洗（三月） |
| **帮工** | 接过浆洗 | 浆洗缝补（三月 350 文）、接绣活（半年 1200 文、技艺 +3）、门口摆茶摊（半年 900 文、声望 +2） |
| **绣娘** | 帮工 + 技艺 ≥45，行「出师」 | 同上 + **帮人接生**（一月：85% 声望 +5，15% 声望 −6） |
| **绣坊主** | 绣娘 + 技艺 ≥70 + 六贯 | 开绣坊（年入 1200）、绣坊收徒 |
| **行首** | 绣坊主 + 技艺 ≥88 + 声望 ≥50 | 掌女红行（年入再 +1300） |

绣坊与行首的收入**归全家**：就算你切回孩子，母亲那间坊子每年照样往里进钱。

母亲出息了，孩子的墓志里也会多一句：「母刘氏，以女红起家，开绣坊于巷口。」

---

**玩伴**：家门口还有两个孩子——阿禾（邻家女孩）和石头（邻家男孩）。12 岁前他们是玩伴（台词是「她蹲在地上用树枝画画，画的是两个小人」），12 岁后台词换成大人的样子（「她已经长成大姑娘了，见了你低头就走」）。

| 玩伴 | 选项 |
|---|---|
| 阿禾 | 一起去河边（三月，身体 +1、声望 +1，记下「河边」）；看她画画（一月，学识 +1） |
| 石头 | 掏鸟窝（三月，技艺 +1、身体 −1）；斗草（一月，声望 +1） |

**童年专属事件**（只在这些岁数会抽到）：出疹子（1–6 岁，身体 −3）、落水（2–7 岁，身体 −2，记下「落水」）、捡到铜钱（3–8 岁，+50 文）、跟邻家孩子打架（3–9 岁，声望 −1）。

这些"记下"的标记会进墓志：「幼时与邻女阿禾戏于河上，捉鱼为乐，是其一生最闲的几年」「幼时曾没于水，赖人救起」。

## 5.5 匠人线（第一条做实的职业路径）

| 阶 | 条件 | 解锁 |
|---|---|---|
| 白身 | — | 铁匠铺「拜师」（匠户 300 文 / 旁人 600 / 读书人 1200） |
| **学徒** | 拜师后 | 铺里帮工（半年 1000 文，技艺 +2） |
| **匠人** | 学徒 + 技艺 ≥40，行「出师」 | 接营造（半年 2600 文）、收徒（每人年入 200） |
| **都料匠** | 匠人 + 技艺 ≥68 + 八贯 | 盘作坊（年入 1500）、接官府营造（一年 6000 文） |

墓志：都料匠 → 「以营造名于州里」；匠人 → 「以手艺名于乡里」。都料匠在墓志判定里直接够【县志一行】，不必拼声望。

其他四条线（农、商、医、军）照这个结构复制即可。

## 5.6 商线

| 阶 | 条件 | 解锁 |
|---|---|---|
| 白身 | — | 市集「摆个小摊」（本钱 200，一月赚 300–900） |
| **行商** | 摆过摊后（自动） | 「跟商队跑一趟」（本钱一贯，六成赚钱 2000–3600，四成亏 400–1000） |
| **坐贾** | 行商 + 已有铺子 + 两万文 | 铺子等级 +1，声望 +10 |
| **行会头目** | 坐贾 + 五万文 + 声望 ≥40，十贯入门 | 每年行会分红 3000；「议行价」可把行情推高 0.10 |

墓志：行会头目 → 「以商起家，为行会之首」；坐贾 → 「以坐贾起家，家道渐丰」。行会头目在墓志判定里直接够【县志一行】。

## 5.7 医线

| 阶 | 条件 | 解锁 |
|---|---|---|
| 白身 | — | 药铺「拜师学医」（600 文） |
| **学徒** | 拜师后 | 帮工（半年 1000 文，医术 +2）、认药（半年，医术 +5） |
| **郎中** | 学徒 + 医术 ≥35，行「出师」 | **出诊**（半年：75% 赚 2200 + 声望 4；25% 赔 600 − 声望 7） |
| **坐堂** | 郎中 + 医术 ≥60 + 声望 ≥30 | 坐堂问诊（一年 4200 文，声望 +6） |
| **名医** | 坐堂 + 医术 ≥85 + 声望 ≥55，著方书 | 声望 +18、学识 +5，此后每年 2000 文 |

医线是第一条**会亏**的职业线：出诊失败既赔钱又掉声望。这也是为什么医和商都适合放在"有风险"的位置——士和匠的路径是稳的。

墓志：名医 → 「以医术名于州里，著方书一卷」；坐堂 → 「以医名于乡里，坐堂三十年」。名医直接够【县志一行】。

## 5.8 农线

这条线是唯一"资产型"的：钱换成田，田产出租子，但**田要缴赋税**（年关 +18 文/亩）。

| 阶 | 条件 | 解锁 |
|---|---|---|
| 白身 | — | 给东家帮工（半年 1700 文） |
| **佃农** | 押租 800 文租八亩 | 佃种（一年 2800 文）、开始能买田 |
| **自耕农** | 有田 ≥6 亩 | 耕种自家的田（900 + 亩×170） |
| **小地主** | 有田 ≥20 亩 | 收租（亩×150） |
| **田主** | 有田 ≥40 亩 | 收租（亩×190）、修水渠（六贯，声望 +12） |

田价随阶上涨：2000 / 2400 / 2800 / 3200 文一亩。四十亩大约要八万八千文——这是现在最大的一个钱坑。

墓志：田主 → 「有田四十亩，岁收租百余石，为一乡之望」；小地主 → 「有田二十亩，衣食粗足」；自耕农 → 「躬耕自给」。

## 5.9 军线

地点是新增的**校场**。这条线第一次让玩家"会死"。

| 阶 | 条件 | 解锁 |
|---|---|---|
| 白身 | — | 应募从军（需身体 ≥45） |
| **乡兵** | 应募 | 操练（半年 500 文，身体 +2）、**出征**（一年 3200 文，**10% 战死**，战功 +1） |
| **厢军** | 战功 ≥2 + 身体 ≥55 | **出征**（一年 4500 文，**8% 战死**，战功 +1） |
| **军官** | 战功 ≥5 + 声望 ≥40 | 巡边（一年 6000 文，声望 +8，**12% 战死**） |

战死不会读档：直接播死亡过场、进墓志，卒年那行写「殁于王事」。

墓志：军官 → 「以军功授官，戍边十余年，身被数创」；厢军 → 「隶厢军，转战南北，未得一言以归」。军官直接够【县志一行】。

## 5.10 人物记忆与随机事件

**人物态度**：每个有名字的人有 `att`（−50…50），由对话选项改变，影响三件事：

| 影响 | 表现 |
|---|---|
| 台词 | 态度 ≥15 走「热络版」台词，≤−15 走「冷淡版」（李婶：笑着招呼你进屋 ↔ 装作没看见） |
| 价格 | 张屠户的肉价 = `80 × (1 − att/250)`，态度 40 时 67 文，−40 时 93 文 |
| 解锁选项 | 李婶态度 ≥15 才出现「她塞给你一篮鸡蛋」 |

**随机事件**：每年有 32% 概率从池中抽一条，按年龄与身份筛选。

| 事件 | 条件 | 效果 |
|---|---|---|
| 旱灾 / 水患 | 8 岁+ | −700 / −900 文，旱灾另 −3 身体 |
| 加派杂税 | 12 岁+ | −500 文，声望 −1 |
| 夜里进贼 | 12 岁+ | −600 文，身体 −2 |
| 疫气 | 10 岁+ | 身体 −7；**医术 ≥60 只 −2** |
| 被人告状 | 16 岁+ | −800 文，声望 −2 |
| 邻家嫁女 | 10 岁+ | −300 文，声望 +3 |
| 丰年 | 有田（自耕农+） | +田亩×60 文 |
| 县里旌表 | 进士或声望 ≥45 | +1200 文，声望 +8 |
| 孩子开蒙 | 有子女 | −500 文，声望 +2 |

"疫气"这条是刻意让医线回头影响世界的：学过医的人遇到瘟疫只病一场小的。

## 5.11 做官线（进士的后半生）

进士之后到衙门「赴任」，掷一个任所（吴县、长洲、常熟、昆山、嘉定、华亭）。

| 阶 | 政绩要求 | 年俸 |
|---|---|---|
| 待选 | — | 2400 |
| **主簿** | 赴任 | 2400 |
| **县令** | 6 | 4800 |
| **通判** | 14 | 8400 |

任期内的三种做法：

| 做法 | 结果 |
|---|---|
| 秉公断案 | 60%：政绩 +2、声望 +3；40%：政绩 +1、声望 −2、赔 500 文（得罪豪强） |
| 收一笔贿 | 钱 +3000、政绩 −1、声望 −3、**贪名 +1** |
| 下乡劝农 | 政绩 +1、声望 +2、身体 −3 |

**贪名攒到 3，年关会自动被御史弹劾**：降一级、声望 −15、追赃 2000 文，墓志里多一句「中岁以赃去官，士论少之」。

这条线是做【国史有传】的主要路径：一路秉公断案到通判，声望能顶到 77 以上。

## 5.12 改行（六条线互通）

一个人可以先后入几条行当，但**中途改行要付代价**：每次入新行当，其余已入行的职业各降一级（田产除外——田是资产，不会因为你去看病就荒掉）。

| 旧业 | 改行后 |
|---|---|
| 匠人 → 学医 | 匠人降为学徒；但**技艺 ≥40 的人医术 +12**（懂火候与药性） |
| 商人 → 从军 | 坐贾降为行商 |
| 军官 → 赴任 | 军职降一级；但**军功在身，赴任时政绩 +2** |
| 坐贾 → 赴任 | 生意降一级；但**懂钱谷，赴任时政绩 +2** |

所以理想的人生不是"选一条路走到黑"，而是"攒够本钱再转"：先做二十年匠人，手艺够了再学医；或者先跑商攒人脉，中年考个官。

底部状态栏会同时列出所有仍在的行当（例：`匠人　行商　医术寻常　田 6 亩　乡兵（功 1）`）。

## 5.13 四角填充

村子四角原本是空草地，补了三处，各有自己的画法：

| 地点 | 位置 | 画法 | 能做的 |
|---|---|---|---|
| 坟地 | 左上 | 绿地上六个土堆 + 石牌，柏树 | 扫墓（100 文，声望 +2）；坐一会儿（身体 +1）；**父母故后**才出现「祭父母」（300 文，声望 +4） |
| 菜园 | 右上 | 四畦菜，土垄 + 菜苗 | 种一畦菜（半年 400 文）；挑菜去卖（三月 600 文） |
| 打谷场 | 左下 | 压平的场院 + 石碾 + 三个草垛 | 帮人打谷（半年 1200 文）；晒粮（三月 700 文） |

这类地块（田、坟地、菜园、打谷场）现在都会在底部挂一个小牌子写名字，不然在草地上认不出来。

## 5.14 时间模型

时间不靠玩家"点动作"来推，它自己走。**基准节奏是一年 = 7 天现实时间**，另设四档流速：

| 流速 | 一年要多久 | 一辈子（60 年） |
|---|---|---|
| **1×**（默认） | 7 天 | 420 天 |
| 60× | 2.8 小时 | 7 天 |
| 600× | 17 分钟 | 17 小时 |
| 3600× | 2.8 分钟 | 2.8 小时 |

左下角「流速」按钮点一下换一档，键盘 `1` `2` `3` `4` 直接切；顶栏一直显示当前流速。

其他规则：

| 规则 | 说明 |
|---|---|
| 动作耗时 | **不耗时**，选什么都不推进时间 |
| 大事跳过 | 只有半年以上的事会跳过一段：跟着父母过一年、跑商队、出征、乡试会试 |
| 暂停 | 打开面板、播过场时时间停住 |
| 昼夜 | 独立一套：一天 ≈ 13 分钟，只影响光影与作息 |

这样"过日子"是连续的：你可以什么都不做，站在村口看一年过去；也可以一口气把事情做完，时间照样在走。

**每一年由六个节令推着走**（这才是玩家实际感受到的"时间加速"）：

| 月 | 节令 | 效果 | 过完跳到 |
|---|---|---|---|
| 正月 | 元日 | 声望 +2 | 三月 |
| 三月 | 清明 | 声望 +2 | 五月 |
| 五月 | 端午 | 身体 +2 | 七月 |
| 七月 | 中元 | 声望 +1 | 八月 |
| 八月 | 中秋 | 身体 +1、声望 +1 | 十一月 |
| 十一月 | 冬至 | 身体 +1 | 次年正月 |

节令在「家」的面板里出现（「过元日（跳过一段时日）」），点开是一个**三选一**：不是确认框，是一次小选择。

| 节令 | 三个选项（择一） |
|---|---|
| 元日 | 挨家拜年（声望 3）/ 守着家里的火盆（身体 2）/ 上街看放炮（声望 1、身体 1） |
| 清明 | 去坟上添土（声望 3）/ 带家里人踏青（身体 2、声望 1）/ 在家抄一天经（学识 2） |
| 端午 | 去看赛舟（声望 2、身体 1）/ 在家包粽子（身体 2）/ 给邻家送一串（声望 3） |
| 中元 | 在路口烧纸（声望 2）/ 去庙里听经（学识 1、声望 1）/ 早早关门睡了（身体 1） |
| 中秋 | 在院里赏月（身体 1、声望 1）/ 去邻家喝酒（声望 2、身体 −1）/ 一个人坐一会儿（身体 1） |
| 冬至 | 一家人吃锅子（身体 2）/ 去祠堂祭祖（声望 3）/ 给穷人送一碗（花 200 文，声望 4） |

一年六次选择，每次三选一——这就是"一年"的实际内容。选完自动跳到下一个节令。

过了窗口（节令月 +2）就不再出现，算作错过了。

**节令会留下记忆**：童年（12 岁前）遇到家里紧（钱 < 250）时，元日/端午/中秋会换成更苦的版本，并记下印记：

| 印记 | 触发 | 墓志 |
|---|---|---|
| 穷yuandan | 童年元日家里没钱 | 少时元日无新衣，母亲把旧袄翻过来缝了一遍 |
| 穷zhongqiu | 童年中秋家里没钱 | 少时中秋无饼，一块糖敲成四份，他分到最小的一点 |
| 童年节令 ≥4 | 12 岁前过满四个节令 | 少时最盼过年，爆竹一响就往外跑 |
| 施舍 | 冬至选"给穷人送一碗" | 岁寒施粥，里中称其厚 |

## 6. 压力与人生节点

**年关**（每年正月自动结算）：吃穿用度与赋税 = `300 + 年龄×4 + 婚配 200 + 子女×180 + 雇工 1800`。

- 付得起：扣钱，提示一句。
- 付不起：钱归零、声望 −2、身体 −1，记一次"欠年"。欠年 ≥3 次，墓志里会写"晚年家道中落"。

**里程碑**：14 岁说亲、18 岁及冠、22 岁讨账、30 岁得子、34 岁再添一子、46 岁丧亲、62 岁抱孙。

**科举**（三年一科，年份见 `data/era/song.json` 的 `exam_years`）：

| 关 | 条件 | 花费 | 成功率 |
|---|---|---|---|
| 解试 | 读过书、学识 ≥25、15–42 岁、开科之年 | 3 个月 + 800 文 | `0.10 + 学识×0.010`（5%–90%） |
| 省试 | 已中举、学识 ≥42、18–45 岁、开科之年 | 12 个月 + 3000 文 | `−0.08 + 学识×0.008`（4%–85%） |

中举 → 声望 +18；中进士 → 声望 +30、赐钱 4000，此后每年领俸禄 2400 文。
落第只扣少量声望，可以再考——但年纪和盘缠都在流失。

**墓志五档**：

| 档 | 条件 |
|---|---|
| 【国史有传】 | 进士 且 声望 ≥68 |
| 【府志留名】 | 进士，或声望 ≥62 |
| 【县志一行】 | 举人，或声望 ≥45 |
| 【族谱一句】 | 有子女或已成家 |
| 【无名】 | 其余 |

跑出来的两组对照（`--stage=village_years`）：

| 玩法 | 结果 |
|---|---|
| 什么都不做 | 20000 文起家，56 岁破产，欠年 26 次 |
| 每年打两份工 | 57 岁善终，遗钱 131,700 文，无欠年 |

## 8. 技术

| 项 | 做法 |
|---|---|

## 9. 已知问题

1. **边缘还是空**：村子中部已经密了，但四角（尤其右下、左上）仍是大片草地。
2. **科举只有"考"没有"做官"**：中了进士只是加声望和俸禄，没有官场线。
3. **钱的上限太低**：进士俸禄 + 铺子收入堆到十几万文，除了墓志上多一句话，没有别的去处。
4. **NPC 无记忆**：赖过账的人和没赖过的人说话一样。
5. **五档里只有两档容易被看到**：中间三档的触发条件还需要实测调平。
