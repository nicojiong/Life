# M1-03a 验证证据：可复现的模拟随机流

- 日期：2026-10-24
- 任务：M1-03（切片 a），审计 A02 / §6 随机分流
- 基线：`2315660`（M1-02c 分支）

## 1. 问题

所有决策都用全局 `randf()`：事件、科举成败、断案、出诊、跑商、出征、巡边、商铺行情。全局流不可存、不可复现，也无法与画面随机分开——**相机多转一帧，下一次人生事件就可能不同**。

## 2. 做法

新增模拟专用流：

```gdscript
var sim_rng := RandomNumberGenerator.new()
var sim_seed := 0
_rnd()   // 0..1
_rndi(a,b)
_rndf(a,b)
```

- 全部**模拟决策**改走 `_rnd*`（正则替换 11 处 `randf()`，并覆盖 `randi_range` / `randf_range`）；
- **画面与游走**仍用各自局部的 `RandomNumberGenerator r`（NPC 相位、速度、游走目标），不进模拟流；
- `_init_identity` 的出身抽取也改用 `sim_seed` 驱动，于是"同种子得到同一个人"；
- 存档写入 `sim_seed` 与 `sim_rng.state`，**用十进制字符串**（64 位整数过 JSON 会丢精度）。

存档版本升到 **4**（v3 → v4 只追加 RNG 字段，缺失时保留启动种子）。

## 3. 断言

```
[VERIFY] PASS rng_reproducible seq=[56, 47, 41] resume=160
[VERIFY] SUMMARY pass=17 fail=0 failed=[]
```

两段验证：

| 段 | 做法 | 断言 |
|---|---|---|
| 同种子同序列 | `_init_sim_rng(12345)` 抽 6 次 → 重新 seed 再抽 6 次 | 两次序列完全相同 |
| 存读档不跳抽 | seed 777 抽一次 → 存档 → 记下"下一次" → 重新 seed 1 → 读档 → 抽一次 | 读档后抽到的正是"下一次" |

第二段是关键：它证明存档保存的是**流的当前位置**，不是重头再来。

## 4. 未覆盖

- 只有一条模拟流；审计建议按 `出生/世界事件/人物决策` 分五类，尚未拆分。
- 没有事实日志（Fact/EventLog），事件还没有 `cause_ids`。
- 没有 `--seed=` 命令行入口，也没有黄金重放 fixture（整段人生逐 tick 比对）。
- 商铺行情、节令、童年事件虽已走 `_rnd`，但没有逐条断言各自可复现。

## 5. 为什么先做这一条

它是后面所有"重放验收"的地基：没有可存可复现的流，就无法回答"这次死亡是随机还是 bug"，也无法做黄金重放。先让**抽取可复现**，再谈分五类流和因果日志。
