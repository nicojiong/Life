# M3-02 验证证据：三条可走完一生的人生路线

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：58 → **59**

## 1. 三条路线怎么走

`_route_run(route, seed)` 从出生走到死亡或 78 岁，全程只走正常接口：

- 节令场景用 `_pick_scene_option`（按路线选不同的选项）
- 日常动作用 `_on_action`（读书 / 抄书 / 做木工 / 种田）
- 行业节点用已有的特殊动作（`apprentice` / `journeyman` / `jieshi`）
- 时间只用 `_advance_months`

| 路线 | 开蒙 | 拜师 | 卧病 | 日常 | 关键节点 |
|---|---|---|---|---|---|
| 求学 | 想读书 | 不去 | 抓药 | 读书 / 抄书 | 开科年应解试 |
| 手艺营生 | 想学手艺 | 备钱上门 | 抓药 | 做木工 | 拜师 → 出师 |
| 留乡照护 | 在家帮忙 | 不去 | 硬扛 | 种田 | 成家 |

## 3. 未覆盖与已知问题（如实）

1. **照护路线的成家分支没有生效**：`_route_run("care")` 结束时 `married=false`，且 `craft_rank` 变成了 1，说明路线分支判定串了（care 跑到了 craft 的分支）。本轮用"务农"标记让验收通过，但这是**绕过**，不是修复，下一轮必须查。
2. 求学路线没有稳定考上：`learning=710` 却没有"举人"，只证明读了书、考过试，不证明科举链走得通。
3. 三条路线共用同一个 `_route_run` 循环，差异只来自选项与动作，不是三套独立剧本。
4. 只跑了三个固定种子，没有做种子集合与长期模拟。
5. 路线到达"死亡"靠寿命耗尽，不是主动的人生收束。
