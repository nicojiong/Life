# M1-05 验证证据：黄金重放

- 日期：2026-10-24
- 任务：M1-05（切片 a），规划中的"黄金重放 fixture"
- 基线：`1ada8d8`
- 断言总数：27 → **28**

## 1. 做法

```gdscript
_replay_digest(seed) -> String
```

1. `_init_sim_rng(seed)`：三条流全部由种子重建；
2. 把状态压回**固定起点**（1046 年 1 月、20 岁、1000 文、学习 20、健康 80、各级 rank 归零、story/relations/cooldown/facts 清空、`last_settled_year = 1045`、关掉年度随机事件）；
3. 按固定命令序列执行：
   - `_advance_months(1)` → `_on_action(读书 +2 学习)` → `_advance_months(1)` → `_on_action(做工 +120 文)` → `_advance_months(1)` → `_on_action(读书)` → `_on_action(12 个月长活 +2000 文 −2 健康)`；
   - 再从世界流抽一次 `_rndi(0,500)`、从人物流抽一次 `_arndi(0,5)`，让种子体现在结果里；
4. 把关键字段拼成摘要串：年、月、年龄、钱、学习、技艺、声望、健康、六个 rank、在世父母数、事实条数、story 条数。

配套 `_replay_snapshot()` / `_replay_restore()` 保存并还原全部会被改动的字段，保证三次重放互不污染。

## 2. 断言

```
[VERIFY] PASS golden_replay digest=y1047|m4|a21|money2241|l28.00|c10.00|f10.00|hp78.00|rank000000|pov1|facts0|story0
[VERIFY] SUMMARY pass=28 fail=0 failed=[]
```

三段比较：

| 比较 | 含义 |
|---|---|
| `digest_a == digest_b`（同 seed 4321 跑两遍） | 同种子同命令 → 同一状态 |
| `digest_a != digest_c`（seed 9999） | 摘要对随机输入敏感，不是"怎么跑都一样" |

## 3. 第一版为什么红

第一版 `digest_c` 和 `a/b` **完全相同**——因为那段固定命令里没有任何随机抽取，种子换了也不影响结果。

这说明断言当时测的其实是"固定命令下的确定性算术"，而不是"随机流可复现"。补上两条流的抽取之后才真正覆盖种子。
