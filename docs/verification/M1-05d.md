## 4. 修掉的两个诊断缺陷

- 比较器返回单条差异时被 PowerShell 展开成字符串，`$d[0]` 取到第一个字符（报告里的"例如 M"）。
- 字段路径匹配用 `-like`，方括号被当成通配符字符集；改为 `.Contains()`。
