## 2. 断言

```

[VERIFY] PASS save_roundtrip_full schema=2
[VERIFY] SUMMARY pass=10 fail=0 failed=[]
```

`save_roundtrip_full` 的流程：

1. 把 `father_trade` 设为「匠」、`mother_temper` 设为「严」、`women_rank` 设为 3、`child_last` 设为「wood」、`time_scale` 设为 600、`scenes_done` 设一条节令记录；
2. `_save_game()`；
3. 把内存全部打乱成默认值，并把 `save_schema_seen` 归零；
4. `_load_game()`；
5. 断言六个字段全部还原，且 `save_schema_seen == 2`。
