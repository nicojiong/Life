# M2-03c 验证证据：后果事实与"因为…所以…"

- 日期：2026-10-24
- 任务：M2-03（切片 c）
- 基线：`923a916`
- 断言总数：36（沿用切片 b 的槽位，内容升级）

## 1. 问题

上一版句子只有事件本身：

> 十三岁那年，旱。

但它没说这场旱**带来了什么**。玩家记得住的往往不是"发生了旱"，而是"因为旱，家里卖了田"。

## 2. 做法

`_drain_due_events` 在应用事件前后各取一次钱与田，差值记成一条**后果事实**，`cause_fid` 指向事件本身：

```gdscript
{"fid": 2, "kind": "consequence", "cause": "event_effect",
 "data": {"id": "drought", "money": -700, "land": -1}, "cause_fid": 1}
```

造句时按 `fid` 找后果，再拼一句后果短语：

| 变化 | 短语 |
|---|---|
| 田 −1 | `，家里卖掉1亩田` |
| 田 +1 | `，家里添了1亩田` |
| 钱 −700 | `，贴进去七百文` |
| 钱 +500 | `，进项五百文` |

于是墓志能写出：

> 十三岁那年，旱，家里卖掉1亩田。

## 3. 断言

```
[VERIFY] PASS epitaph_story_lines ["十三岁那年，旱，家里卖掉1亩田。"]
[VERIFY] SUMMARY pass=36 fail=0 failed=[]
```

校验三件事：句子以「十三岁那年，旱」开头、包含「亩田」、并且空日志时仍然不生成任何句子。

## 4. 一个真 bug：读错了层级

第一版短语永远是空的。加了一行调试输出才看清：

```
[DBG] facts=2 cq=6 evfid=1 line_len=8 has_land=-1
```

`cq=6` 说明后果**找到了**（6 个字段），但 `has_land=-1` 说明短语里没有田。

原因：数值存在事实的 `data` 里，我却直接从事实顶层 `cq.get("land")` 取——拿到 0，`d_land < 0` 不成立，短语返回空串。

修成 `cq.get("data", {}).get("land")`。

**这个 bug 不会报错、不会崩，只会让句子悄悄变短**。如果没有断言卡住"必须包含亩田"，它会一直静默地少半句话。

## 5. 未覆盖

- 只摘了钱与田两种后果；声望、健康、故事标记的变化没有进句子。
- 后果按"事件前后差值"算，混在一起的变化无法归因（例如同一事件既扣钱又扣健康）。
- 事件与后果之间只有一层因果，没有"旱→卖田→佃种"这种多跳句。
- 短语模板仍是硬编码。
