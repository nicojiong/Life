- 日期：2026-10-24

## 1. 改动

| 位置 | 改动 |
|---|---|
| `_trigger_actor_end()` | 新增。`ended` 只置一次；按视角决定 `_ending()` / `_parent_death()` |
| `_advance_months()` | 每次迭代先判死活；到寿立即结束并返回，删除静默 return |
| `_on_action()` | 跳时后、特殊效果后各检查 `ended`，中断则 return |
| `_save_game()` | `ended` 时拒绝写入 |

## 2. 断言输出

```
[VERIFY] PASS isolated_user_dir .../LifeVerify-<id>
[VERIFY] PASS origins_count 10
[VERIFY] PASS newborn_state age=0 can_walk=false
[VERIFY] PASS save_roundtrip money=12345
[VERIFY] PASS parents_present
[VERIFY] PASS father_trade_mapping
[VERIFY] PASS merchant_origin_wired
[VERIFY] PASS npc_ids_unique count=14
[ACTION] interrupted_before_reward 长活
[VERIFY] PASS death_blocks_reward money=1000
[VERIFY] SUMMARY pass=9 fail=0 failed=[]
```

脚本汇总：`断言 pass=9 fail=0 exit=0`、`PASS 真实存档目录未被触碰`、exit=0。

## 3. `death_blocks_reward` 怎么测的

1. 把 `age` 设成 `lifespan`（40/40），`money` 设成 1000；
2. 调 `_on_action({"months":12, "gain":{"money":5000}})`；
3. 断言 `ended == true` 且 `money` 仍是 1000。

第一版**测出的是真问题**：`_advance_months` 在循环第一次迭代就因为 `age >= lifespan` 走了末尾的静默 `return`，既没结束人生，也没拦住收益，钱变成了 6000。修掉静默 return 之后才通过。
