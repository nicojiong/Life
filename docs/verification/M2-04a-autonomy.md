# M2-04 验证证据：分阶段自主权

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：55 → **56**
- 存档 schema：17 → **18**

## 1. 三个阶段

| 阶段 | 年龄 | 规则 |
|---|---|---|
| 幼年 `infant` | 0–6 | 行动被拦，且**给出可读理由**（"六岁前，家里替你做主"） |
| 少年 `minor` | 7–14 | 能表达倾向（读书/手艺/帮工），能拒绝家里安排，行动仍受年龄门槛 |
| 成年 `adult` | 15+ | 门槛放开 |

## 2. 新增机制

| 名称 | 作用 |
|---|---|
| `_action_block_reason(act)` | 返回人话原因：年龄不足 / 阶段不足 / 家里停供 |
| `_choose_preference(pref)` | 7 岁后选方向；家里钱 < 200 选读书 → `family_refused` 并记 `story["家里供不起"]` |
| `_refuse_family_arrangement()` | 7–15 岁拒绝家里安排：`story["没听家里的"]`、`story["家里不再供你读书"]`、父母关系各 −1、倾向设为 `self` |
| 场景「开蒙」 | 三月触发（7–12 岁、尚未表态）：想读书 / 想学手艺 / 想在家帮忙 / 不想听家里的 |

## 3. 断言

```
[VERIFY] PASS autonomy_stages infant=true young=true minor=true poor=true refuse=true adult=true reload=true
[VERIFY] SUMMARY pass=56 fail=0 failed=[]
```

七段：

1. 3 岁行动被拦，理由含"六岁前"；
2. 3 岁不能自选倾向（`too_young`）；
3. 8 岁能选"学手艺"，倾向写入；
4. 家里只剩 50 文时选读书 → `family_refused`，`story["家里供不起"]` 留痕，倾向仍记 `study`；
5. 10 岁拒绝家里安排 → 关系下降、`story["没听家里的"]`、倾向 `self`；
6. 拒绝后 `study` 行动给出"不再供你读书"的具体理由；
7. 成年后门槛放开；存读档保持倾向。

## 4. 未覆盖

- 倾向只影响标记，还没有改变童年事件权重（下一步接 `_child_year`）。
- "拒绝"没有后续和解分支，关系只降不升。
- 幼年没有真正的"家庭代为决定"事件（抓周、启蒙选择仍由玩家在场景里点）。
- 家里供不起读书时，没有"自学/借书"替代路径。
