# M2-04 验证证据：分阶段自主权

- 日期：2026-10-24
- 任务：M2-04（切片 a）
- 基线：`4a02f56`
- 断言总数：36 → **37**

## 1. 问题

此前只有**地点级**门槛（`MIN_AGE`：太小的孩子进不了市集），没有**行动级**门槛。

于是十岁的孩子能在私塾面板里看到「赴京应省试」，五岁的孩子能看到「说亲」——只要那个地点本身对他开放。

## 2. 做法

三个阶段：

| 阶段 | 年龄 | 含义 |
|---|---|---|
| `infant` | 0–6 | 蒙养之年，由父母带着过 |
| `minor` | 7–14 | 渐知人事，能做的事还少 |
| `adult` | 15+ | 自己拿主意 |

两个门槛字段，任一不满足就不显示：

```gdscript
{"special": "jieshi", "min_age": 12}
{"special": "expedition", "min_age": 16, "min_stage": "adult"}
```

- `_action_gated(act)`：`age < min_age` 或当前阶段低于 `min_stage` → 过滤掉；
- `_open_panel` 在生成按钮时跳过被过滤的行动；
- 面板副标题显示当前阶段（「（蒙养之年，由父母带着过）」）。

先接了四个最明显的：解试 12、省试 16、赴任 18、随军出征 16。

## 3. 断言

```
[VERIFY] PASS autonomy_stage_gates infant->minor->adult
[VERIFY] SUMMARY pass=37 fail=0 failed=[]
```

| 年龄 | 检查 |
|---|---|
| 5 | 阶段是 `infant`；「15 岁才能做」被挡；无门槛的行动仍可做 |
| 10 | 阶段是 `minor`；`minor` 级行动可做；`adult` 级被挡 |
| 20 | 阶段是 `adult`；`adult` 级行动可做 |

## 4. 未覆盖

- 只接了 4 个行动，其余仍是"任何年龄都能点"。
- 阶段是按年龄算的，没有考虑"是否成家/是否读书/是否当家"这些状态。
- 0–6 岁仍然可以点开地点面板看（只是里面的行动被过滤），没有真正的"父母替你做决定"。
- 面板副标题的措辞没有做本地化/内容化。
