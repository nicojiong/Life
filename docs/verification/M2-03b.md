# M2-03b 验证证据：墓志用事实写出具体年份

- 日期：2026-10-24
- 任务：M2-03（切片 b）
- 基线：`ee4541f`
- 断言总数：35 → **36**

## 1. 问题

上一版墓志只有一句统计：

> 一生所记：应试2次、逢变故1次。

它知道"发生过几次"，不知道"哪一年、什么事"。而玩家真正会记住的，是**具体那一年**。

## 2. 做法

给事件定义补 `name`（`旱`/`水`/`加赋`/`盗`/`疫`/`讼`/`婚嫁`/`丰年`/`旌表`/`入学`/`疹`/`落水`/`拾钱`/`口角`），再用事实日志还原年龄：

```gdscript
func _age_at_month(t: int) -> int:
    return int(t / 12) - birth_year

func _story_lines() -> Array:
    # 只写真实发生过的事实，最多 3 条
```

输出形如：

> 十三岁那年，旱。
> 二十岁，解试落第。

墓志在"一生所记"之后插入这些句子。

## 3. 断言

```
[VERIFY] PASS epitaph_story_lines ["十三岁那年，旱。"]
[VERIFY] SUMMARY pass=36 fail=0 failed=[]
```

两段：

1. `birth_year = 1040`、事实发生在 1053 年 4 月 → 必须生成**逐字等于**「十三岁那年，旱。」的句子（不是"包含关键字"）；
2. 清空事实后再取，必须返回空数组——**没有事实就不编句子**。

## 4. 过程中的一次误伤

用 `{"id": "school", ` 做替换时，同时命中了事件表和**建筑表**里的私塾，把建筑行改成了两个 `name` 键，编译直接报 `Key "name" was already used`。

`--check-only` 精确指到 2542 行，改回去即可。教训：按 id 做全局替换时，先确认这个 id 在别的表里没有同名的。

## 5. 未覆盖

- 只写事件与科举两类，死亡、婚配、债务还没进句子。
- 句子模板写死在代码里，没有走内容数据。
- 最多 3 条，按日志顺序取前三条，不是按"重要性"挑。
- 因果链（M2-03a）还没用于造句；现在是"某年发生了某事"，不是"因为某事所以某事"。
