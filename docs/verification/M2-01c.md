## 1. 非当前人物被事件扣到 0 健康

### 问题

`_apply_event_to_inactive` 只把健康写进 `actor_vitals`，**从不判死**。于是操控父亲时孩子被扣到 0 健康，存读档、再推进一年，`_actor_is_dead("child")` 仍然返回 `ended`（false）——一个"活的死人"，还能接住 `transfer` 的事件。

### 修复

1. `_actor_is_dead("child")` 除了 `ended`，还看健康是否 ≤ 0；
2. 新增 `_settle_actor_death(who, cause)`：按 actor_id 结算——孩子死 = 这一局结束（必要时先切回孩子再出结局），父母死 = 登记本人名下、当前视角若正是他则切回孩子；
3. 新增 `_check_actor_deaths()`：遍历 `child/father/mother`，健康归零或到寿都走同一条结算；
4. `_apply_event_to_inactive` 结束时调用它；
5. 年边界补一条：非当前视角的孩子健康归零，走 `_settle_actor_death("child")` 并结束这一年。

## 2. 取消的事件不算"发生过"

### 问题

`_drain_due_events` 在结算**之前**就写了一条 `kind: "event"` 的事实；取消/转移又各写一条 `kind: "event"`。于是取消父亲的一场疫病，墓志里会冒出两句「二十岁那年，疫」，统计成两次变故。

### 修复

先结算、按结果决定写什么：

| 结果 | 写入的事实 |
|---|---|
| `applied` | `event`（真实发生） |
| `transferred` | `event` + 转移说明 |
| `cancelled_dead_target` | `event_cancelled_dead_target`（**不算发生**） |
| `cancelled_unknown_target` | `event_cancelled_unknown_target` |

`_story_lines` 只数 `kind == "event"`，所以取消不会再进墓志。

## 3. 旧档事件缺少 target

schema 12 的事件实例没有 `target`/`policy` 字段。读档时：

```gdscript
inst_l["target"] = ""              # 未知主体，不是"孩子"
inst_l["legacy_unknown_target"] = true
inst_l["policy"] = "cancel"
```

到期时 `who == ""` → `cancelled_unknown_target`：**不假装能恢复主体，也不静默交给孩子**。

## 5. 未覆盖

- `_check_actor_deaths` 在事件路径上同步调用，可能在同一帧里连锁（父母→孩子）；目前只测了单跳。
- 转移只允许转给孩子，没有"转给配偶/其他家人"。
- 旧档事件被取消时没有面向玩家的提示，只有事实日志。
- 取消/转移的事实种类没有进 `_facts_trace` 的统计，墓志不会提到"有一件祸事躲过去了"。
