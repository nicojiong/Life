# M1-01a 验证证据：关系由世界持有，不随场景重建消失

- 日期：2026-10-24
- 任务：M1-01（切片 a），审计 A05
- 基线：`bf0846f`（M1-03c 分支）

## 1. 问题

好感 `att` 存在 `npcs[]` 这个**表现层数组**里，而 `_spawn_npcs()` 每次重建都创建 `att: 0` 的新条目。

于是：切视角 → 关系清零；读档 → 关系清零；场景重建 → 关系清零。

具体后果：李婶记得你帮她挑过水（+25），可你切去当了三年父亲再切回来，她又是陌生人；张屠户的肉价也回到 80 文。

审计 A05 的原话是"当前记忆不能支撑十年后仍记得玩家的行为"。

## 2. 做法

关系搬进世界状态：

```gdscript
var relations: Dictionary = {}   # id → attitude

func _get_att(id) -> int: return int(relations.get(id, 0))
func _set_att(id, v): relations[id] = v; 同步更新场景里的镜像
```

- `_spawn_npcs()` 生成 NPC 时用 `_get_att(id)` 初始化镜像，而不是 0；
- 对话加好感走 `_set_att`（写世界，再镜像）；
- `relations` 入库（schema 5 → **6**）。

场景里的 `att` 字段**降级为镜像**：只用于显示与局部判断，真值只有 `relations` 一份。

## 3. 断言

```
[VERIFY] PASS relations_survive_rebuild rebuild=25 load=25
[VERIFY] SUMMARY pass=20 fail=0 failed=[]
```

三步：

1. `_set_att("li_shen", 25)`；
2. `_spawn_npcs()` 重建场景 → 断言仍是 **25**（这条在改动前必然失败，因为重建会写回 0）；
3. 存档 → 清空内存 → 读档 → 断言仍是 **25**。

## 4. 这一条为什么排在这里

它不属于"大重构"，但它正是审计 A05 的**最小可观测症状**：一个你帮过的人，会不会在你离开一会儿之后还记得你。

先让关系有一个明确的持有者，比先拆 Actor 类更能立刻改善"这个世界有没有记忆"的感受。

## 5. 未覆盖

- 关系仍是一维 `att`，没有拆成信任/亲近/恩怨/债务；也没有"重要经历"的事件引用。
- 父母、孩子没有关系值（他们只有 `pov_state` 与死亡记录）。
- 关系没有随时间衰减，也不会因为第三方行为改变。
- 场景里的 `att` 镜像与 `relations` 之间仍是"写时同步"，不是单向派生；如果以后有人直接改 `npcs[i]["att"]`，会再次分叉。
