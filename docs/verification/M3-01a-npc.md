# M3-01a 验证证据：核心 NPC 独立生活（3 人验证）

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：57 → **58**
- 存档 schema：18 → **19**

## 1. 三个核心 NPC

| NPC | 目标 | 自主行为（按处境分支） |
|---|---|---|
| 李婶 | 帮衬邻里 | 玩家穷或病 → 送米 +60 文、健康 +1；否则只是串门 |
| 王秀才 | 教书糊口 | 玩家识字 ≥20 或已拜师 → 借书 +3 识字；玩家"没听家里的" → 劝一句；否则自己读书 |
| 张屠户 | 做生意 | 玩家"欠债未还" → 拒绝赊账、关系 −2；玩家有钱 → 多切二两肉 +40 文；否则照常出摊 |

每个人有：`goal`、`attitude`（与 `relations` 同步，关系是权威）、`memory`（年份 + 事实 id + 一句话）、`last_year`、`alive`、`wealth`。

## 2. 关键设计

- **不依赖玩家点击**：`_npc_year_tick()` 在年边界自动执行，每人每年一次
- **态度差就明确拒绝**：`attitude <= -2` 时走 `npc_<id>_refuse`，不是随机沉默
- **记忆指向真实事实**：`_npc_remember` 存 `fid`，断言逐个校验 `_fact_exists(fid)`
- **真的改变世界**：钱、识字、健康、关系、后续机会都会变

## 3. 断言

```
[VERIFY] PASS npc_independent_life facts=0->9 remembered=3 goals=3 reload=true
[VERIFY] SUMMARY pass=58 fail=0 failed=[]
```

六件事：

1. 玩家什么都不做，推进 3 年 → NPC 事实从 0 涨到 9（**世界自己动了**）；
2. 玩家数值也变了（钱/识字），证明 NPC 行为真的影响世界，不只是写日志；
3. 三个 NPC 目标互不相同；
4. 至少 2 人留下记忆，且每条记忆的 `fid` 都能在事实里找到；
5. 关系压到 −5 → 下一年记录 `npc_li_shen_refuse`；
6. 存读档后 NPC 状态与记忆条数保持。

## 4. 修掉的三个真问题

1. `golden_replay` 变红：`npc_state` 没进重放快照/还原 → 两次重放结果不同（补进快照后恢复）；
2. NPC 记忆串联了旧局：`_continuity_start` 没重置 `npc_state`，上一局 1041–1058 年的记忆混进新局（已在起点重置）；
3. 态度缓存不同步：拒绝分支读的是 `npc_state.attitude`，关系改了却不生效（改为行动前从 `relations` 同步）。
