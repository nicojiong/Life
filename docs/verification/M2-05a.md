# M2-05 验证证据：0–18 岁因果切片

- 日期：2026-10-24
- 任务：M2-05（切片 a）
- 基线：`04979c9`
- 断言总数：37 → **38**

## 1. 目标

前面所有切片都是单点验证：一次跳时、一次年关、一次事件、一条句子。没有一个测试**从头活到成年**。

这条切片从出生跑 18 年，检查整条链是否还站得住。

## 2. 做法

```gdscript
func _run_life_slice(seed_value: int, years: int) -> Dictionary
```

1. `ended = false`、固定种子、`_init_identity()` 重建一个新生儿；
2. 打开年度机会（`events_enabled = true`），清空边界日志；
3. 每年 `_advance_months(12)`，记录该年的：是否结算（`settle`）、自主阶段、钱是否变负、健康是否越界；
4. 中途死亡则提前停止。

返回 `{age, ended, settles, stages, money_ok, hp_ok, facts, dead}`。

## 3. 断言

```
[VERIFY] PASS life_slice_0_18 age=18 settles=18 facts=23
[VERIFY] SUMMARY pass=38 fail=0 failed=[]
```

七项同时成立才算过：

| 检查 | 含义 |
|---|---|
| `age >= 18` | 真的活到成年（种子 2024 下未早死） |
| `not ended` | 中途没有被判定死亡 |
| `settles == 18` | **每一年都结算了一次**，不多不少 |
| `money_ok` | 18 年里钱没变成负数 |
| `hp_ok` | 健康始终在 0–100 |
| 见过 `minor` 与 `adult` | 阶段真的推进过 |
| `facts > 0` | 这 18 年确实发生了被记录的事（本次 23 条） |

`settles == 18` 是这条切片最有用的一项：它一次性验证了"年边界每年恰好触发一次"在**长期运行**下也成立，而不是只在单次调用里成立。

## 4. 过程中修的两个错

1. **插入函数时把文件读回覆盖**：脚本先 `Replace` 加了 `_run_life_slice`，随后又 `ReadAllText` 把 `$src` 重读了一遍，写入的是**原始内容**——函数根本没进文件。断言里已经调用了它，于是编译失败。
2. **循环体缩进错了**：生成断言时 `saw_minor = true` 与 `if` 同级，GDScript 报 `Expected indented block after "if" block`。按行号直接改缩进修好。

两次都是"我知道要编译，但没先编译"。`--check-only` 本可以在写完后立刻发现问题。

## 5. 未覆盖

- 只跑固定种子（2024）。换种子可能早死——早死也是合法人生，但这条断言的语义是"能活到成年"，所以种子被固定住，并在文档里写明。
- 切片是从出生开始的**无操作**人生：不点任何行动，只让时间走。它验证的是"不玩也不会崩"，不是"玩得动"。
- 没有断言童年事件的具体内容（几条、都是什么），只断言日志非空。
- 没有断言节令（`YEAR_SCENES`）在 18 年里都触发过。
