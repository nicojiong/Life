# M1-05 验证证据：跨进程续跑（首个场景）

- 日期：2026-10-24
- 基线：`32932b0`
- 断言：50（smoke 不变）；续跑是独立 job，不混入断言总数

## 1. 三个进程

| 进程 | 做什么 | 产物 |
|---|---|---|
| A | 固定种子跑 N 步，`_save_game()`，导出检查点，退出 | `cont_a.json`、存档 |
| B | **新进程**读档（不带 `--fresh`），立即导出，再跑 M 步，导出终态 | `cont_b0.json`、`cont_b1.json` |
| C | 另一套干净目录，从同一起点连续跑 N+M 步 | `cont_c.json` |

种子在 `_continuity_start()` 里**先于** `_init_identity()` 设置；B 完全不播种。

## 2. 快照从权威状态导出

`_continuity_snapshot()` 直接读运行中的字段，不复用 `_state_dict()` 的存档清单：

- 人物：三人各自的 `age/health/lifespan/dead` + 完整 `pov_state` 行（职业、田亩、故事标记）
- 家庭：`money`、`parents_alive`、婚育、`land`
- 关系：`relations` 全量
- 队列：`event_instances` 全量（含 `sid/target/policy/due/fired`）与 `event_seq`
- 冷却：`action_cooldown` 全量
- 随机流：`rng_world/actor/birth` 三条的 `state`
- 事实：`facts` 全量（内容 + 顺序）、`fact_seq`、`fact_floor`
- 时间：`year/month/month_frac/time_scale`、`last_settled_year`
- 死亡：`parent_dead`、`parent_death_year`、`scenes_done`

`month_frac` 此前**不在存档里**，本轮补进 schema 13 并存读，否则续跑必然丢月内进度。

## 3. 本地实跑结果

```
A 快照 year=1045 month=9 frac=0.0 facts=8
B0 快照 year=1045 month=9 frac=0.0 facts=8
B1 快照 year=1046 month=9 frac=0.0 facts=16
C  快照 year=1046 month=9 frac=0.0 facts=16
A vs B0：一致
B1 vs C：一致
```

业务不变量（不是"两边相等"而已）：

- 读档后年月必须等于检查点年月；
- B 续跑后时间必须推进；
- C 路径必须产生事实（否则场景空转也会"一致"）；
- B 的事实序号不得回退。


## 5. 已知的数值表示归一

第一条真实差异是 `0` vs `0.0`：内存里是 int，读档后 JSON 解析成 float。比较器把**所有数值统一成 double** 再比，字段结构、字符串、数组顺序都不放宽。

这不是删字段——`int`/`float` 是同值的两种表示；字段缺失、值不同、顺序不同仍然会红。

## 6. 未覆盖

- 只有"正常跨年"一个场景；父母视角待办、死亡边界、非零 `month_frac` 保存点尚未接入。
