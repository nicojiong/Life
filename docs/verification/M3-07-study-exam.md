# M3-07 验证证据：求学路线打通科举（真的中举了）

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：仍 64 条，但 `m3_routes_walkable` **口径变严**

## 1. 之前为什么一次都没中举

`m3_routes_walkable` 过去用"识字 ≥100"当求学路线的证据——这不是功名，是偷懒。

真跑数据一看：

- 20 岁时识字已经是 **109**（节令场景给的多，早过 25 的解试门槛）；
- 但 20 岁那年 `money=0`，而应解试要 800 文；
- 路线里的抄书一年只赚 80 文，家里年关要花 950 文上下——**学生永远攒不够盘缠**，于是每逢开科年都被钱卡住。

一句话：不是考不上，是根本没钱去考。

## 2. 修法

| 改动 | 旧 | 新 |
|---|---|---|
| 抄书（识字 <30） | 80 文 / 年 | **400 文 / 年** |
| 替书院校书（识字 ≥30） | 500 文 / 年 | **1200 文 / 年** |
| 读书 | +2 识字 | **+3 识字** |
| 省试 | 无（路线里没接） | 中举后识字 ≥42、钱 ≥3000 时赴京 |
| 断言口径 | 识字 ≥100 就算过 | **必须有"举人"或"进士"** |

## 3. 现在的断言输出

```
[VERIFY] PASS m3_routes_walkable study=76/109.0 degree=true craft=64/2 care=62/true
[VERIFY] SUMMARY pass=64 fail=0 failed=[]
```

`degree=true` 是这次新加的字段——它直接读 `story["举人"]` / `story["进士"]`。断言能在"必须有功名"的条件下通过，说明**求学路线真的走完了科举这一步**。

## 4. 顺带发现

- `_apply_gain` 把识字钳在 0–100，但节令场景直接 `learning += 2` 绕过钳制，所以识字能到 109。这个不一致还没修——它让"读书"在 100 之后完全无效。
- 长跑 6 次（2 种子 × 3 路线）仍然全过：`long_run_seeds runs=6 age=67-72 min_facts=240`。

## 5. 未覆盖

- 只验证了"有一次中举"，没有验证进士/做官这条更长的链。
- 中举后的省试用的是同一套识字门槛，没有单独的内容（没有举人社交、没有同年、没有座师）。
- 科举概率仍是 `0.10 + 识字×0.01`，与家境、师承、地域无关。
