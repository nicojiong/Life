## 2. 断言输出

```
[VERIFY] PASS isolated_user_dir .../LifeVerify-<id>
[VERIFY] PASS origins_count 10
[VERIFY] PASS newborn_state age=0 can_walk=false
[VERIFY] PASS save_roundtrip money=12345
[VERIFY] PASS parents_present
[VERIFY] PASS father_trade_mapping
[VERIFY] PASS merchant_origin_wired
[VERIFY] PASS npc_ids_unique count=14
[VERIFY] SUMMARY pass=8 fail=0 failed=[]
```

`tools/verify.ps1` 汇总：`断言 pass=8 fail=0 exit=0`，`PASS 真实存档目录未被触碰`，脚本 exit=0。

## 3. 断言含义

| 断言 | 防的是什么 |
|---|---|
| `father_trade_mapping` | 五种出身 flag 到父亲行当的映射整体回归；任一映射写错都会红 |
| `merchant_origin_wired` | 数据里确实有「商贾」出身，且它真的被解析成「商」——防止只改代码不改数据、或反之 |
| `npc_ids_unique` | 已生成的 NPC 不允许重复 id，防止标签重叠与点击歧义 |
