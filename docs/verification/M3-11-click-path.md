# M3-11 验证证据：面板能点 ≠ 真能用（点击链路断言）

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：67 → **68**

## 1. 补的缺口

上一轮只证明"识字 130 时书院面板里会出现开馆授徒"——那只是**列表里有个字符串**。会不会点下去没反应、时间不推进、冷却不设？没人验过。

本轮补上点击链路：

```
取动作 → _on_action(act) → 检查钱、时间、冷却 → 还原状态
```

## 2. 断言

```
[VERIFY] PASS academy_teaching_clickable found=true money=true time=true cooldown=true
[VERIFY] SUMMARY pass=68 fail=0 failed=[]
```

四件事：

| 检查 | 含义 |
|---|---|
| `found` | 面板里确实取到了这条动作 |
| `money` | 点完之后钱 ≥1500（真的到账，不是文案） |
| `time` | 月索引前进 ≥11（12 个月真的有代价） |
| `cooldown` | 点完之后同一动作进入冷却，不能连点刷钱 |

## 3. 做法细节

- 用 `_replay_snapshot()` 在点击前存档，`_replay_restore()` 在断言后还原，避免污染后面的长跑与档案断言；
- 只有"取到动作"时才调用 `_on_action`，否则会拿空字典去跑，报错会伪装成失败；
- 冷却用 `_action_key(act)` 与 `_cooldown_ready(key)` 判定，和真实 UI 走同一套逻辑，不是另写一套判断。

## 4. 未覆盖

- 仍是"直接调用 `_on_action`"，**没有经过真实的鼠标点击与面板重建**；按钮文案、禁用态、面板刷新都没验。
- 只验了开馆授徒这一条，其余几十条面板动作没有同样的点击级断言。
- 12 个月内跨年年关（结算、事件、衰老）会发生，但断言只比较月索引差，没有核对年关是否被正确触发一次。
