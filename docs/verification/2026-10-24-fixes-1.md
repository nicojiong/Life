# 第一轮修复：旧档视角迁移与赴任路径

- 日期：2026-10-24
- 基线：`7260b84`
- 断言总数：41 → **43**

## 1. 旧档迁移会把父亲的血条安到孩子身上

### 问题

`_load_game()` 的旧档迁移里写着：

```gdscript
actor_vitals["child"] = {"age": age, "health": health, "lifespan": lifespan}
```

`age`/`health`/`lifespan` 是**当前视角那个人**的全局字段。当老存档停在"操控父亲"时，这三个值属于父亲——于是孩子的年龄变成了父亲的 44 岁，健康 66，寿数 70。

读档后切回孩子，会看到一个 44 岁的"孩子"。

### 修复

```gdscript
# 全局字段属于当前视角的人，不能一律当成孩子
actor_vitals[pov] = {age, health, lifespan}

if not actor_vitals.has("child"):
    # 旧档没存孩子时，用年号推算年龄，给中性健康值，绝不抄当前视角
    actor_vitals["child"] = {
        "age": maxi(0, year - birth_year),
        "health": 80.0,
        "lifespan": 60,
        "estimated": true,
    }
```

### 三个 fixture

| 文件 | 视角 | pov_state | 期望 |
|---|---|---|---|
| `save_v1_child.json` | child 10 岁 | 父 44 / 母 41 | 孩子 10、父亲 44 |
| `save_v1_father.json` | father 44 岁 | 母 41 / 孩子 10 | 孩子 10、父亲 44 |
| `save_v1_mother.json` | mother 41 岁 | 父 44 / 孩子 10 | 孩子 10、父亲 44 |

断言 `old_save_pov_migration` 逐个读档并核对：**视角正确 + 孩子仍是 10 岁 + 父亲仍是 44 岁**。

父亲 fixture 是关键用例——修复前它会把孩子的年龄改成 44。

## 2. 赴任抽县名的类型错误

### 问题

```gdscript
func _pick_from(pool: Array) -> Dictionary:   # 返回类型写死成 Dictionary
...
county = str(_pick_from(names))               # names 是 Array[String]
```

随机流本身没问题，但函数签名承诺返回 `Dictionary`，实际返回 `String`。赴任（`take_post`）这条路一走就会抛类型错误——而它此前从未被任何断言覆盖。

### 修复

- `_pick_from` 返回类型改为 `Variant`，并注明池里可能是 Dictionary（事件）或 String（城名）；
- 赴任处显式判类型，兜底取第一个县名。

### 断言

```
[VERIFY] PASS take_post_assigns_county county=华亭
```

真实调用 `_apply_special("take_post")`，断言官职升到主簿、县名是长度 ≥ 2 的字符串。

## 3. 顺带修的一个连锁

三个 fixture 跑完后视角停在最后一个（母亲）。后面的 `death_blocks_reward` 于是走了"送父母"而不是"自己死"，断言变红。

修复：fixture 循环结束后显式切回孩子视角并清 `ended`。
