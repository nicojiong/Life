# M2-05 验证证据：0–18 岁因果切片

- 日期：2026-10-24
- 任务：M2-05（切片 b，覆盖切片 a）
- 基线：`04979c9` → 本轮 `b526734`
- 断言总数：**38**

## 1. 目标

从出生跑到成年，检查整条链在**长期、连续**运行下是否站得住，并且真的"有内容"：节令过没过、童年事件有没有发生。

## 2. 做法

```gdscript
_run_life_slice(seed, target_age) -> Dictionary
```

1. 固定种子重建新生儿，打开年度机会；
2. **按年龄收口**（`while age < 18`）而不是按迭代次数；
3. 每年：`_advance_months(12)` → 模拟玩家关掉面板（`busy = false`）→ 把到期的节令逐个个过掉（选第一项）；
4. 结束时统计：年龄、是否死亡、年关次数（取自 `year` 事实）、阶段序列、钱/健康是否越界、节令次数、童年事件次数。

## 3. 断言

```
[VERIFY] PASS life_slice_0_18 age=18 settles=18 facts=78
[VERIFY] SUMMARY pass=38 fail=0 failed=[]
```

九项同时成立：活到 18、未死亡、**18 次年关**、钱不变负、健康不越界、见过 minor 与 adult、事实非空、**节令 ≥ 50 次**、童年事件 ≥ 3 次。

## 4. 这条切片揪出的真问题

### 4.1 童年事件在正常游玩里从未触发

`_child_year()` 只被两个**调试舞台**调用（`--stage=child` 与一个调试特例）。正常游玩中，0–6 岁的"由父母带着过、每年抽一条"从未发生。

这不是小问题：它正是"0 岁开始、剧本有父母陪伴"这个需求的核心循环。

修法：年度事件的阶段按年龄分流——

```gdscript
if age < 7:
    _child_year()      # 蒙养之年：不由玩家选，父母带着过
else:
    _roll_event()
```

修完后切片里童年事件从 0 变成 6（0–6 岁每年一条）。

### 4.2 节令会额外推进时间，迭代次数 ≠ 年数

第一次跑出来 `age=36`：18 次循环跑出了 36 岁。原因是节令选完会跳到下一个节令（`_scene_months_to_next`），时间被额外推进。

改成按 `age` 收口后，18 次循环变成 9 次，但年数正确。

### 4.3 结算次数不能数循环

`settles` 原先统计"每次迭代后 boundary_log 里有没有 settle"，结果只数到 9 次。

改成从事实里数：年关每年记一条 `year` 事实 → `settles = _count_facts("year")`，得到 18。

**"数循环"和"数世界事件"是两件事**，这条断言又一次证明了这一点。

## 5. 未覆盖

- 只跑固定种子（2024）。换种子可能早死——早死也是合法人生，但这条断言语义是"能活到成年"。
- 切片是"无操作人生 + 第一节令选项"：不点任何地点行动，验证的是时间与世界推进，不是"玩得动"。
- 节令只选第一项，没有测不同选项的分支。
- 童年事件只验数量，没验内容是否与父母性情/家境匹配。
- 事实上限 240 条，18 年已经 78 条；更长的人生会被截断（链条会断，见 M2-03 的遗留项）。
