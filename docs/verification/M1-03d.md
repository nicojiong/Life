# M1-03d 验证证据：三条可保存的模拟随机流

- 日期：2026-10-24
- 任务：M1-03（切片 d），审计 §6 随机分流
- 基线：`d7e6d52`
- 存档版本：6 → **7**

## 1. 问题

上一版只有一条 `sim_rng`。事件、科举、断案、出诊、跑商、巡边、商铺行情全挤在一个流里。

后果：**做过一次杂事，科举的"运气"就变了**。同一个种子本应得到同一段人生，但任何一次额外抽取都会平移整条流。

## 2. 做法

按用途拆成三条**可保存**的流，另有两类**不进模拟**的随机：

| 流 | 用途 | 是否入库 |
|---|---|---|
| `rng_birth` | 出身、姓名、父母年龄与寿数 | 是 |
| `rng_world` | 年度事件、事件池挑选、商铺行情、城名 | 是 |
| `rng_actor` | 科举成败、断案、出诊、跑商、出征、巡边 | 是 |
| 表现层 | NPC 游走、相位、速度（各动作里的局部 `r`） | 否 |
| 调试 | 无 | — |

三个种子由同一基底派生（`s`、`s+1`、`s+2`），存档写 `sim_seed` 与三条流的 `state`（十进制字符串）。

## 3. 断言

```
[VERIFY] PASS rng_reproducible seq=[56, 47, 41] resume=160
[VERIFY] PASS rng_streams_independent actor=[339, 278, 24]
[VERIFY] SUMMARY pass=27 fail=0 failed=[]
```

`rng_streams_independent` 的做法：

1. seed 2025，抽 3 次人物流 → 记下；
2. 重新 seed 2025，先抽 **7 次世界流**，再抽 3 次人物流；
3. 两组人物流结果必须完全一致。

这条断言在拆分前必然失败——当时只有一条流，世界流抽 7 次会把人物流一起推走。
