# M3-09 验证证据：名望/手艺/医术统一写入口，识字上限接上收益

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：65 → **66**

## 1. 清理"两套规则"的剩余部分

上一轮只统一了识字。这轮把名望 / 手艺 / 医术也收口：

| 项 | 之前 | 现在 |
|---|---|---|
| 写入口 | 散落 **46 处** `x = minf(100.0, x + n)` / `maxf(0.0, x - n)` | 全部改为 `_add_fame` / `_add_craft` / `_add_medicine` |
| 上限 | 各写各的 100 | `SKILL_CAP := 100.0` 单一定义 |
| 识字 | `LEARNING_CAP := 200.0` | 不变 |

替换后代码里已无 `fame/craft/medicine = minf|maxf|clampf(...)` 的直接写法（唯一保留的是三个 helper 内部）。

## 2. 让 200 上限有收益

识字到 120 之后，求学路线的糊口方式升级：

```
learning ≥ 120 → 开馆授徒：钱 +1500，识字 +2，名望 +3
learning ≥ 30  → 替书院校书：钱 +1200，识字 +4
否则           → 抄书：钱 +400，识字 +2
```

以前识字顶到 200 只是个数字，现在高识字能换来稳定收入与名望。

## 3. 断言

```
[VERIFY] PASS stat_caps_unified fame=true/true craft=true medicine=true learning=true distinct=true
[VERIFY] SUMMARY pass=66 fail=0 failed=[]
```

六件事：

1. 名望 99 + 5 → **100**（封顶）；
2. 名望 0 − 5 → **0**（不穿底）；
3. 手艺 95 + 10 → **100**；
4. 医术 100 + 5 → **100**；
5. 识字 199 + 5 → **200**；
6. 技能上限与识字上限**确实不同**（100 ≠ 200），不是把两者混成一个常量。

其余 65 条断言（长跑、档案、家庭、NPC、科举）全部无回归；求学路线仍是 `degree=true`。

## 4. 未覆盖

- 开馆授徒只在求学路线里接上，界面上的书院面板还没有这个选项。
- 名望 100 之后没有任何新内容，仍是硬顶。
