# M2-01b 验证证据：事件实例绑定承受者

- 日期：2026-10-24
- 基线：`4dabd61`（PR #1 的 head）
- 断言总数：46 → **47**

## 1. 问题

事件实例只记了"什么时候到期、什么事件"，没记"谁的事"。到期时 `_apply_event(id)` 直接改**当前视角**的全局字段。

后果：给孩子排的旱灾，切到父亲再到期，扣的是父亲的血；主体在到期前死了，事件照样落在你正在操控的人身上。

## 2. 做法

实例增加两个字段：

```gdscript
{"sid": 3, "id": "drought", "due": 12645, "fired": false,
 "target": "child", "policy": "cancel"}
```

| 字段 | 含义 |
|---|---|
| `target` | 稳定人物 id（`child` / `father` / `mother`），入队时默认取当前视角 |
| `policy` | 主体已死时的处理：`cancel`（默认，取消）或 `transfer`（转给孩子） |

到期结算走唯一入口 `_apply_event_for(target, id, policy)`：

| 情况 | 行为 |
|---|---|
| 主体就是当前视角 | 照旧 `_apply_event`（含文案） |
| 主体活着但不是当前视角 | `_apply_event_to_inactive`：个人影响写他自己的 `actor_vitals`/`pov_state`，家庭资产仍进共用的钱袋 |
| 主体已死 + `cancel` | 记 `cancelled_dead_target` 事实，**不产生任何影响** |
| 主体已死 + `transfer` | 转给孩子（孩子也死了就取消），记 `transferred` 事实 |

## 3. 断言

```
[VERIFY] PASS event_actor_binding child=true father=true cancel=true restore=true once=true
[VERIFY] SUMMARY pass=47 fail=0 failed=[]
```

五段，对应要求的四条回归：

| 段 | 场景 |
|---|---|
| `child` | 给孩子排旱灾 → 切到父亲 → 到期：**孩子的血掉了，父亲没变** |
| `cancel` | 父亲已死，排给他的事件到期：钱一分没动、队列已清空、当前视角不受影响 |
| `restore` | 排给母亲、`transfer` 策略、+2 月到期 → 存档 → 清空 → 读档：**target/policy/due 三项完全一致** |
| `once` | 同一实例第一次 drain 触发 1 次，第二次触发 0 次 |

## 4. 未覆盖

- `transfer` 只在"主体死亡"时触发，没有"移居/失踪"等其他失效态。
- 非当前视角的事件不弹文案，只写事实——玩家不会被告知"家里出事了"，只有回望时能看到。
- `_apply_event_to_inactive` 对 `plague`/`harvest` 是简化口径（按目标自己的 `med_rank`/`land`），与当前视角路径不完全等价。
- 个体事件与家庭资产仍是同一个钱袋，"谁的钱"没有细分。
