# M1-02c 验证证据：每个角色各自老化

- 日期：2026-10-24
- 任务：M1-02（切片 c），审计 A06
- 基线：`1c0b47f`（M1-02b 分支）

## 1. 问题

年度结算只作用在**当前操控的角色**的全局字段上：

```gdscript
if age > 48: health -= 0.8
if age > 60: health -= 1.4
```

替父亲过日子时，父亲的健康在掉；可切回孩子之后，父亲的健康**再也不动**——他会永远停在 39 岁那份血条上，永远不会老死。反过来，孩子在被操控时也不会因为父母视角的十几年而变老。

审计 A06 的说法是"世界结算依赖当前控制谁"。这就是最小可观测的一例。

## 2. 修复

抽出纯函数 `_decay_health(age, hp)`，年关时对**所有在世角色**逐一应用：

| 对象 | 处理 |
|---|---|
| 当前操控者 | 直接改全局 `health` |
| 缓存中的父母 / 孩子（`pov_state`） | 改 `st["health"]`，并按各自 `lifespan` 判定死亡 |
| 父母死亡 | 写 `parent_dead` / `parent_death_year`，`parents_alive-1`，重建 NPC，提示「也走了，就在这一年」 |

父母在你不操控时死掉，不需要切过去看——年关那一 tick 就会记下来。

## 3. 断言

```
[VERIFY] PASS actors_age_independently father_hp=39.2 self_hp=60.0
[VERIFY] SUMMARY pass=16 fail=0 failed=[]
```

流程：

1. 把父亲的缓存状态设成 55 岁、健康 40；
2. 当前视角仍是孩子，健康设 60；
3. `money` 给足 50000（避免欠年扣血干扰观察）；
4. 调一次 `_on_new_year()`；
5. 断言：父亲健康 40 → **39.2**（55 岁，每年 −0.8），孩子健康仍是 **60.0**（未成年不掉血）。

## 4. 又一次是断言不干净

第一版跑出来 `self_hp=59.0`，看着像"孩子也被扣了血"。实际原因是上一条测试留下的 800 文不够付 854 文年关，走了"欠年"分支把健康 −1。

加上 `money = 50000` 之后才真正只观察老化。这已经是本轮第三次"断言没有隔离住它要测的东西"——写测试时把无关变量钉死，比写被测代码更容易出错。

## 5. 未覆盖

- 年关**支出**仍按当前操控者的年龄/婚配/子女计算，不是按户结算——真正的修法需要 Household 聚合（M1-01）。
- 父母在缓存里死亡时只给一句 toast，没有过场；切过去看遗物、办丧事都还没有。
- `pov_state` 里的孩子状态（替父母过日子时的孩子）同样只老化扣血，不参与年关支出。
- 全家的钱仍是一个池子，没有"谁挣的、谁花的"。
