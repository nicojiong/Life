# M2-03a 验证证据：借米因果链

- 日期：2026-10-25
- 分支：`agent/m2-m3`
- 断言：52 → **53**
- 存档 schema：14 → **15**（新增债务字段）

## 1. 机制

| 项 | 设计 |
|---|---|
| 单位 | 斗，一斗 = 200 文（`RICE_UNIT_VALUE`） |
| 债主 | 村东孙四（稳定 id `sunsi`，关系存在 `relations`） |
| 借款 | `_borrow_rice(units)`：钱 +units×200，写入债务，入队到期事件（+6 月） |
| 到期 | 队列事件 `debt_due`，主体是借款人；到期够钱自动还，不够判赖账 |
| 偿还 | `_repay_debt()`：钱够才扣，取消到期事件，关系 +2，`story["借米还清"]` |
| 延期 | `_defer_debt()`：**从原到期日顺延 3 个月**，取消旧实例、建新实例，最多 2 次，关系 −1 |
| 拒绝 | 场景选项直接拒绝，关系 +1，`story["谢绝借米"]` |
| 资源不足 | 还钱接口返回 `insufficient`，不改变任何状态，只记 `repay_failed` 事实 |
| 赖账 | 关系 −3，`story["欠债未还"]`，到期实例一次性消费 |

**后续机会**：还清过米的人会解锁 `neighbor_guarantee`（有人作保，+800 文 + 声望），冷却 60 个月，只发生一次。这是"关系变化带来实际后续帮助"，不只是好感数字。

## 2. 玩家可见入口

| 场景 | 条件 | 选项 |
|---|---|---|
| `jiemi`（六月·青黄不接） | 钱 < 300 且无债 | 借三斗 / 只借一斗 / 咬牙不借 |
| `debt_month`（九月·还米） | 有未还债务 | 把米还上 / 再宽限三个月 / 赖着不还 |

两个场景都进 `YEAR_SCENES`，带 `cond` 由 `_scene_ok` 过滤；选项走 `_pick_scene_option` 的专用分支，不套通用增益。

## 3. 断言

```
[VERIFY] PASS debt_chain borrowed=true repay=true defer=true default=true reload=true
[VERIFY] SUMMARY pass=53 fail=0 failed=[]
```

六段，用例自带干净起点（22 岁、无债、清掉"还清"标记）：

1. **22 岁仍可借**：借 3 斗 → 钱 +600，队列里有 1 条 `target=child` 的到期实例；
2. **资源不足**：钱 500 时还 600 → 返回 `insufficient`，债务状态不变；
3. **还清**：钱 900 还 600 → 剩 300、状态 `repaid`、解锁作保机会；
4. **延期**：再借 2 斗、延期 → 旧实例被取消、新到期 = 原到期 +3 月、延期计数 1；
5. **赖账**：钱 0 时到期 → `defaulted`，再结算一次返回 `no_debt`（不重复）；
6. **存读档**：借款+延期后存盘，清内存，读档 → 状态/斗数/到期/延期次数全部一致。

## 4. 修掉的两个真 bug

1. `_cancel_event` 的函数体被缩进到 `continue` 之后，**永远执行不到、永远返回 false**（M2-02a 发现，本轮修）；
2. `_defer_debt` 原本从"现在"重新算 3 个月，导致延期反而可能**提前**到期；改为从原到期日顺延。

## 5. 未覆盖

- 债主只有孙四一人，没有多债主/多笔债并行。
- 利率固定为 0，没有"借一斗还斗半"。
- 作保机会只加钱与声望，没有引入新的 NPC 关系链。
- 场景选项没有做"钱不够点还米"的禁用态，只是选后提示失败。
- 债务状态未进人生档案叙述（M3-04 补）。
