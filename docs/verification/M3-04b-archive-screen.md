## 1. 改了什么

上一轮我自己列的不足：档案只写进 `user://life_archive_<slot>.json`，玩家在游戏里看不到。

`_epitaph()` 末尾接上两段：

```
—— 一生章回 ——
十八岁，拜了师，学手艺。
二十二岁，成了家。
三十岁，家里添了孩子。
五十七岁，欠着米没还。
—— 后人评 ——
村里人提起你，说这人是做过事的。
```

- 章回最多显示 6 条，来自 `last_archive["chapters"]`，每条都带 `fid`（可追溯）；
- 评价单独成段，**排在章回之后**，与事实分开；
- 完整 JSON 仍然落盘，界面只取摘要。

## 2. 断言

```
[VERIFY] PASS archive_on_screen chapters=4 sections=true verdict_after=true
[VERIFY] SUMMARY pass=64 fail=0 failed=[]
```

四件事：

1. 结局页出现「一生章回」与「后人评」两段；
2. 至少 3 行形如"N岁，……"的章回；
3. `verdict.line` 出现在「后人评」之后（评价没有混进章回段）；
4. 章回内容来自 `last_archive`，不是临时拼的字符串。
