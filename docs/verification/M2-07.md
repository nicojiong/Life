# M2-07 验证证据：童年事件真的被家庭塑造

- 日期：2026-10-24
- 任务：M2-04/M2-05 的内容补齐
- 基线：`575f8af`
- 断言总数：39 → **40**

## 1. 问题

`CHILD_EVENTS` 里一直有 `"mother": "严"`、`"cond": "poor"` 这些字段，筛选逻辑也真的在跑——但玩家感受不到差别：

- 事件文案是固定的一句话，不管父亲是匠人还是农夫；
- 家境贫富只影响"能不能抽到当镯子"，不影响读起来的样子。

## 2. 做法

`_child_year()` 在应用事件之后，再补一句**家庭风味**：

```gdscript
match father_trade:
    "匠": "父亲在院里刨木头，刨花落在你脚边。"
    "商": "父亲在灯下打算盘，珠子声一直响到你睡着。"
    "兵": "父亲在磨刀，磨一会儿就抬头看看门口。"
    "吏": "父亲在抄文书，纸边堆得老高。"
    _:   "父亲从地里回来，鞋上都是泥。"

if money < 300:   "锅里是稀的。"
elif money > 3000: "灶上还留着肉。"
```

于是同一件"打碎了碗"，匠人家的孩子在刨花堆里跪着，农人家的孩子在泥鞋边跪着。

## 3. 断言

```
[VERIFY] PASS child_events_shaped_by_family craft=24 farm=22
[VERIFY] SUMMARY pass=40 fail=0 failed=[]
```

四段检查：

| 检查 | 期望 |
|---|---|
| 母亲"严" + 事件要求"严" | 可抽 |
| 母亲"严" + 事件要求"和" | 不可抽 |
| 家境 100 文 + `cond:poor` | 可抽 |
| 家境 5000 文 + `cond:poor` | 不可抽 |

再加上两句风味必须**不同**且各自含关键词（匠→「刨」、农→「泥」）。

长度不同（24 vs 22）是顺带证据，但断言靠的是内容而不是长度——只比长度的话，换个等长句子就能骗过。

## 4. 未覆盖

- 风味句在事件 toast 之后单独弹一条，不是拼进同一句（视觉上是两行）。
- 只有父亲行当与家境两个维度，没有用上母亲性情（它只影响抽不抽得到）。
- 文案是硬编码，没有走内容数据（M3 要解决的事）。
- 断言只覆盖四种父亲行当中的两种。
