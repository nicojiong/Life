## 3. 合并前应知的风险

1. **只有 Linux CI**：Windows 本地通过，但窗口/字体/平台差异未在 CI 覆盖。
2. **续跑共用同一段运行函数**：C 与 A+B 走同一个 `_continuity_run`，同函数 bug 会同时出现在两边而不被发现。这是结构性盲点。
3. **`frac` 场景偏弱**：只验证恢复值与算术探针，没有真的让时间跨阈值再核对结算时机。
4. **忽略清单为空**：没有显式声明"允许忽略的运行元数据"，等于全部参与比较；好处是严，坏处是未来加 UI 字段会误报。
5. **无真人试玩**：所有验证都是自动化的，未验证可玩性与手感。
