## 要解决的问题（审计 A01）

`_on_action()` 先跳时，跳时可能已经进入 `_ending()` 并清档，但返回后仍继续 `_apply_gain()`、`_apply_special()` 和 `_save_game()`。后果：

- 跨过寿终的长行动会**死后发奖**；
- 清档之后又写回一份普通存档，等于"死亡被撤销了一半"；
- `_advance_months()` 在"年龄已达寿数"时会**静默 return**，不触发结局——人物卡在活着与死去的边界上。

## 范围与方案

允许改动：

- `scripts/street/village_scene.gd`：`_advance_months`、`_on_action`、`_save_game`，新增 `_trigger_actor_end()` 与一条断言
- `docs/tasks/M0-04.md`、`docs/verification/M0-04.md`、`docs/agent/*`

不做：不建独立人生档案（属后续任务）；不改经济与内容数值。

实施：

1. 新增 `_trigger_actor_end()`：`ended` 只置一次；按当前视角决定 `_ending()` 或 `_parent_death()`。
2. `_advance_months()` 每次迭代先判死活，到寿立即结束并返回，去掉静默 return 的分支。
3. `_on_action()` 在跳时之后、特殊效果之后各检查一次 `ended`，中断则不打收益、不写档，并打印 `[ACTION] interrupted_*`。
4. `_save_game()` 在 `ended` 时拒绝写入并打印 `[SAVE] refused_after_end`。

## 验收

| 验收项 | 判定 | 结果 |
|---|---|---|
| 跨寿终长行动不发奖 | 断言 `death_blocks_reward`：`age == lifespan` 时执行 12 个月带 `gain.money=5000` 的行动，钱保持不变 | 通过（money 仍为 1000） |
| 死亡只触发一次 | `_trigger_actor_end()` 以 `ended` 守卫；`_ending()` 自身首行也判 `ended` | 通过 |
| 结束后命令被拒绝 | `_on_action()` 首行 `if ended: return`；`_save_game()` 拒绝 | 通过 |
| 不再静默清档又重写 | 中断路径直接 return，不进入 `_save_game()` | 通过 |
| 死亡判定先于完成收益 | 跳时后立即检查，收益在检查之后 | 通过 |
