## 要解决的问题

仓库此前没有任何自动验证：`--stage=*` 只做赋值和打印，`--shot=` 只证明某帧能渲染，退出码不表达成败；而 `--fresh` 会无条件删掉 `user://` 下四个存档文件，直接在真实目录里跑测试等于删玩家存档。

审计 A01/A04 等问题需要的回归门禁，必须先有一个**隔离且带退出码**的验证入口。

## 范围与方案

允许改动：

- 新增 `tools/verify.ps1`、`docs/verification/M0-02.md`、`docs/tasks/M0-02.md`
- `scripts/main.gd`：`--fresh` 加守卫、新增 `verify_smoke` 舞台分发
- `scripts/street/village_scene.gd`：新增 `_run_verify_smoke()` 断言入口

不做：不改游戏规则、不改存档格式、不新增内容、不修 A01–A05 缺陷（属 M0-03/M0-04）。

方案：

1. 用「复制项目 + 改写 `config/name`」实现 `user://` 隔离（Godot 4.7 没有 `--user-data-dir`，已核对 `--help`）。
2. 断言写在游戏内（`verify_smoke`），通过 `quit(0/1)` 返回退出码。
3. 脚本比对真实存档目录运行前后的文件名/大小/mtime，确认隔离生效。
4. `--fresh` 仅当 `LIFE_ALLOW_SAVE_WIPE=1` 且在隔离目录时执行。
