## 要解决的问题（审计 A09）

1. `data/origins.json` 的商人出身 flag 是 **`商贾`**，而 `_init_identity()` 判断的是 **`商人`**，导致该出身的 `father_trade` 落回默认「农」——商人家族的父亲在做农活，且直接影响童年事件筛选与父亲台词。
2. NPC 表里 `lao_seng` **连续定义两次**，`_spawn_npcs()` 会生成两个同 id 的老僧，名称标签重叠、点击命中不确定。
3. 没有内容校验：重复 ID、无效 flag 不会被发现，属"改完也没人拦得住"的状态。

3. 在 `verify_smoke` 增加：`father_trade_mapping`、`merchant_origin_wired`、`npc_ids_unique`。
