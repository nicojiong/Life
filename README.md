# 浮生

> 北宋村庄人生模拟。你在村里出生，点地走动、点人说话、点屋做事，从六岁活到死。

- 引擎：Godot 4.7（GDScript），Windows 桌面
- 画面：全部即时绘制，无图片素材（皮影/版画风）
- 设计文档：[docs/GDD.md](docs/GDD.md)

---

## 现在能玩到什么

| 系统 | 状态 |
|---|---|
| 地图 | **3200×1900 的村庄**，右上角小地图显示位置与视野框 |
| 镜头 | **手动**：右键拖动 / 方向键 / WASD 平移，点小地图跳转，按 **F** 回到人物；人不在画面里时边缘有红点提示 |
| 走动 | **A\* 寻路**：点地面任意处，人物沿格子绕开房屋走过去；点屋顶则走到门口 |
| 童年 | **从 0 岁出生开始**：0–2 岁**不会走路**（不能寻路，画面上是一小团襁褓跟着母亲）；2 岁学步之后才能走；0–6 岁「家」只有一个选项「跟着父母过日子（一年）」，每年由父母带着过（14 条引导事件）；1 岁抓周、6 岁开蒙 |
| 换视角 | **左下角常驻「父亲 / 母亲 / 自己」三个按钮**，一键切换；各有年龄/身体/技能/职业/寿数，钱全家共用，世界时间共用；父母寿终会自动切回孩子 |
| 母亲的妇业 | 切到母亲后「家」变成她自己的路：浆洗 → **绣娘**（接绣活/摆茶摊）→ **绣坊主**（开坊，年入归全家）→ **行首**（掌女红行）；中途可帮人接生（有风险） |
| 地点 | **22 处固定地点 + 空地**：家 / 私塾 / 田 / 市集 / 书院 / 寺庙 / 衙门 / 茶肆 / 药铺 / 祠堂 / 铁匠铺 / 酒肆 / 当铺 / 瓦舍 / 桑园 / 染坊 / 客栈 / 校场 / 码头 / 坟地 / 菜园 / 打谷场 / 空地（16 岁后可盘铺子） |
| 街上的人 | **10 个有名有姓的人**（李婶 / 王秀才 / 张屠户 / 老僧 / 货郎 / 里正 / 稳婆 / 游医 / 船夫 / 老塾师）；另有 8 个无名路人走动 |
| 对话 | 点头上带名字的人 → 走过去 → 开口。每个选项都会改钱、属性或留下 flag |
| 故事事件 | 14 岁媒人上门说亲（不可逆，影响墓志）；借过李婶的米，22 岁会有人上门讨账 |
| 行动 | 每个地点 2–3 个行动，消耗时间（1–12 个月）并结算钱、学识、技艺、声望、身体 |
| 时间 | **时间自己走** + **节令推着走**：基准一年 = 7 天现实时间；每年六个节令（元日/清明/端午/中元/中秋/冬至）在「家」里过，每个都是**三选一**，选完跳到下个节令；童年家里穷时节日会换成苦版本并**写进墓志**；左下角「流速」或 `1`/`2`/`3`/`4` 切 1×/60×/600×/3600×；动作不消耗时间 |
| 年关 | 每年正月自动结算吃穿用度与赋税（300 + 年龄×4 + 婚配 200 + 子女×180 + 雇工 1800）；付不起就典当、扣声望与身体，记一次"欠年" |
| 科举 | 私塾/书院读书 → **开科之年**（三年一科）在书院应**解试** → 中举后应**省试** → 进士。进士每年领俸禄 2400 文 |
| 做官线 | 进士后到衙门**赴任**（主簿）→ 断案攒政绩 → 政绩 6 升**县令** → 政绩 14 升**通判**；收贿攒够贪名会被**弹劾贬官** |
| 改行 | 可以先后入几条行当，但每次入新行会**把其他职业各降一级**（田产除外）；有衔接加成：技艺 ≥40 学医多 +6 医术，军功/坐贾出身赴任政绩 +2 |

| 人物记忆 | 每个人有态度值：影响**台词**（热络/冷淡两版）、**价格**（张屠户肉价 67–93 文浮动）、**解锁选项**（李婶对你好才送鸡蛋） |
| 随机事件 | 每年 32% 概率触发：旱灾、水患、加税、盗贼、瘟疫（学过医可减免）、官司、嫁娶、丰年、旌表、孩子开蒙 |
| 出身差异 | 匠户出身拜师只要 300 文；读过书的人去拜师要 1200 文（师父觉得奇怪） |
| 人生节点 | 14 说亲、18 及冠、22 讨账、30 得子、34 再添一子、46 丧亲、62 抱孙 |
| 结局 | 墓志**五档**：国史有传 / 府志留名 / 县志一行 / 族谱一句 / 无名，按功名 + 声望 + 家室判定 |
| 自由营生 | 16 岁后村口空地可盘下包子铺（8 贯）/ 绸庄（18 贯）/ 首饰铺（30 贯） |
| 店铺经营 | **进货 → 定价 → 开门做半年 → 雇伙计 → 重装门面**。行情 0.70–1.40 每月漂移，同行也会改价 |
| 过场演出 | 开张、十八岁及冠、死亡时全屏演出（黑场 + 月轮 + 逐字字幕） |
| 昼夜与季节 | **一天约 13 分钟**（一个时辰约 66 秒），夜里会暗下来；四季各一套色调，冬天落雪 |
| 音效 | 7 个程序化合成的音效（点击、脚步、开柜、进账、钟、失败、成事），无外部素材 |
| 存档 | 三个存档槽，每次行动/对话/过年自动写当前档；`[` `]` 换档，F5/F9 手动存读；死亡或「再活一世」清当前档 |
| 引导与打磨 | 底部一行随处境变的提示（该读书 / 该说亲 / 该盘铺子 / 家里快断粮）；建筑按 id 有不同墙色屋顶，铺子挂竖幌（茶/酒/药/铁/当），衙门有石狮，学塾有碑；音量可调并记忆 |

一局大约 50–80 次点击。

## 操作

1. **右键拖动**（或方向键 / WASD）移动镜头；点小地图可直接跳过去；按 **F** 回到人物
2. **点地面**：小人寻路走过去（途中显示目的点与剩余路径点）
3. **点屋子**：走到门口，弹出面板
4. **点人**（头上带名字的）：走过去说话
5. 选一个行动 → 时间推进 → 顶部显示结果
6. 「离 开」关掉面板

其它按键：

| 键 | 作用 |
|---|---|
| `[` / `]` | 切换存档槽（1–3，切换时自动先存当前档） |
| `F5` / `F9` | 手动存档 / 读当前档 |
| `-` / `=` | 主音量 −3 dB / +3 dB（写进 `user://settings.cfg`） |

## 运行

双击 `play.bat`，或：

```powershell
& "D:\Developer\Godot\4.7.2-stable\Godot_v4.7.2-stable_win64.exe" --path "."
```

开发时截图 / 调试（`--stage=` 直接跳到某个状态）：

```powershell
$g = "D:\Developer\Godot\4.7.2-stable\Godot_v4.7.2-stable_win64_console.exe"
# 村庄 / 拖动后的另一角
& $g --path "." -- --stage=village --shot=docs/shots/village.png --wait=1400 --fresh
& $g --path "." -- --stage=village_pan --shot=docs/shots/village_pan.png --fresh
# 跑 60 年，看年关与里程碑（控制台会打印结果）
& $g --path "." -- --stage=village_years --fresh
# 夜晚
& $g --path "." -- --stage=village_night --shot=docs/shots/village_night.png --fresh
# 冬季（落雪）
& $g --path "." -- --stage=village_winter --shot=docs/shots/village_winter.png --fresh
# 店铺面板 / 一次完整营业
& $g --path "." -- --stage=village_shop
& $g --path "." -- --stage=village_shop_run
# 对话（直接开 / 走过去再开）
& $g --path "." -- --stage=village_dialog
& $g --path "." -- --stage=village_talk
# 存档往返验证
& $g --path "." -- --stage=village_save --fresh
& $g --path "." -- --stage=village_load
```

`--fresh` 会先删掉存档，保证截到的是新开局。

## 已知缺口

完整的静态审计见 [docs/strategy/00_REPOSITORY_AUDIT.md](docs/strategy/00_REPOSITORY_AUDIT.md)，摘要见 [docs/GDD.md](docs/GDD.md) 第 9 节。当前最要紧的是三条工程缺陷，而不是内容量：

1. **A01 死亡不是可靠的结算终点**——行动跨过寿终时可能仍然发奖，清档后又写入普通存档
2. **A02 存档不完整**——父亲行当、母亲性情、妇业级别、节令记录、流速等未入档，读档后可能变回新随机值
3. **A03 死亡与旧档缺字段同状态**——父母死亡用"从状态里删除"表示，读档又按旧档补生成，可能复活

内容层面的已知问题：墓志偏重功名，普通与独身人生容易落到"余无可书"（A10）。
